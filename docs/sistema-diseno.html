04 / Movimiento

Blur reveal

  1. Hero letra por letra: blur 12px → 0, escala 0,95 → 1, Y 30 → 0, stagger 80 ms, easing [0.16, 1, 0.3, 1], 0,8 s.
  2. Bloques: opacidad 0 → 1, Y 40 → 0, 1 s, una sola vez al entrar.
  3. Parallax ±15% y disipación con desenfoque al hacer scroll.
  4. Trazo del isotipo con stroke-dashoffset en 3 s; flotación de 6–8 s.
  5. Sin rebote ni elástico. No animar top, left, width ni height.
